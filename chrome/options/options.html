使用说明

  • 步骤 1：切到“API 设置”填写服务地址、Key、模型并保存。
  • 步骤 2：点击“测试连通性”确认接口可用。
  • 步骤 3：回到“功能开关”开启 README 翻译，再按需开启高级功能。
  • 步骤 4：在“翻译记录”查看 tokens 消耗、缓存命中与翻译状态。

选择当前使用的翻译平台。翻译目标语言固定为简体中文（zh-CN）。不同厂商会预填适合 README 翻译的快速高性价比模型。

DeepL 配置

DeepL Free 默认地址：`api-free.deepl.com`，Pro 账号可改为 `api.deepl.com`。

在 DeepL 控制台生成，通常以 `:fx` 结尾（Free 套餐）。

Google Cloud Translation 配置

推荐使用 v2 端点。若走代理网关，可替换为你的网关地址。

请确保该 Key 已启用 Cloud Translation API 权限。

Microsoft Translator 配置

默认是全球端点；若使用私有区域端点，请填你的专属地址。

来自 Azure AI Translator 资源密钥。

必填，如 `eastasia`、`koreacentral` 等。

Qwen-MT 配置

Qwen-MT 是专用机器翻译模型，默认使用 OpenAI 兼容 Chat Completions 地址，并通过 `translation_options` 指定翻译目标。

来自阿里云百炼 / Qwen Cloud 的 API Key。

默认 `qwen-mt-turbo`，可按额度和质量需求改为 `qwen-mt-flash`、`qwen-mt-plus` 或 `qwen-mt-lite`。

AI 对话接口配置

选择上方厂商后会自动预填官方 base URL 与模型。自定义 OpenAI 兼容接口也可填完整 `/chat/completions` 地址。为通过商店审核并降低权限风险，默认仅支持 HTTPS（本地 localhost 可用 HTTP）。

支持 Bearer Token 鉴权的 OpenAI Chat Completions 兼容接口。

填接口实际可用的模型名，大小写请与平台要求一致。

点击后会用当前表单配置发送一次最小测试请求，不会修改页面内容。首次测试某个 API 域名时，浏览器会弹出域名访问授权提示。若返回 401/403/429，请先检查 API Key 权限、额度和模型名。
