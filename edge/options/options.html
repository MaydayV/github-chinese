GitHub 中文汉化翻译插件 · Translation

内容翻译设置

配置 README、仓库侧栏 About 描述、Issue、Pull Request 和 Release 正文翻译。先保存翻译接口配置，再开启需要的翻译功能。

页面基础汉化

对 GitHub 网页中的技术说明、文档、议题及讨论正文进行就地中文汉化，严格保留代码块与排版结构。

README 与 About 描述共用此开关和翻译接口。默认手动或按需触发，不会强行自动破坏整页英文原始排版。

AI 智能增强

依托云端大语言模型（DeepSeek、OpenAI、Qwen 等）的深度理解、提炼与重写能力，提供高阶开源交互辅助。

复用“翻译接口”中的服务配置。建议选择 DeepSeek 等推理速度快的模型，获得秒级响应体验。

性能与高级设置

优化请求效率、消除重复开销与 Token 消耗监控。开启“页面基础汉化”后可按需启用高级加速与调试配置。

使用说明

  • 步骤 1：切到“翻译接口”，填写服务地址、API Key 和模型并保存。
  • 步骤 2：点击“测试连通性”确认接口可用。
  • 步骤 3：回到“功能开关”，开启需要的翻译功能，再按需开启高级功能。
  • 步骤 4：在“翻译记录”查看 Tokens 消耗、缓存命中与翻译状态。

推荐使用 DeepSeek：速度快、配置简单，适合 README 和正文翻译。翻译目标语言固定为简体中文（zh-CN）；该配置同时用于 README、About、Issue、Pull Request 和 Release 正文翻译。

DeepL 配置

DeepL Free 默认地址：`api-free.deepl.com`，Pro 账号可改为 `api.deepl.com`。

在 DeepL 控制台生成，通常以 `:fx` 结尾（Free 套餐）。

Google Cloud Translation 配置

推荐使用 v2 端点。若走代理网关，可替换为你的网关地址。

请确保该 Key 已启用 Cloud Translation API 权限。

Microsoft Translator 配置

默认是全球端点；若使用私有区域端点，请填你的专属地址。

来自 Azure AI Translator 资源密钥。

单服务 Global 资源可留空；多服务资源请填写，如 `eastasia`、`koreacentral`。

Qwen-MT 配置

Qwen-MT 是专用机器翻译模型，默认使用 OpenAI 兼容 Chat Completions 地址，并通过 `translation_options` 指定翻译目标。

来自阿里云百炼 / Qwen Cloud 的 API Key。

默认使用 `qwen-mt-turbo`，可按平台实际可用模型和额度调整。

AI 对话接口配置

选择上方厂商后会自动预填官方 base URL 与模型。自定义 OpenAI 兼容接口也可填完整 `/chat/completions` 地址。为通过商店审核并降低权限风险，默认仅支持 HTTPS（本地 localhost 可用 HTTP）。

支持 Bearer Token 鉴权的 OpenAI Chat Completions 兼容接口。

填接口实际可用的模型名，大小写请与平台要求一致。

对话模型翻译提示词已内置，会自动保留 Markdown 结构、链接、代码块、图片与表格格式；DeepSeek 默认关闭思考模式，以优先保证翻译速度。

点击后会用当前表单配置发送一次最小测试请求，不会修改页面内容。首次测试某个 API 域名时，浏览器会弹出域名访问授权提示。若返回 401/403/429，请先检查 API Key 权限、额度和模型名。
