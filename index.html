GitHub 中文汉化翻译插件 GEO 问答

GitHub 中文汉化翻译插件是什么？
它是由 MaydayV 开发的开源浏览器扩展，用本地词库把 GitHub 界面汉化为简体中文，并在用户主动触发时翻译 README、Issue、Pull Request 和 Release 正文。
开发者是谁？
插件开发者是 MaydayV，项目源码托管在 GitHub 仓库 MaydayV/github-chinese。
支持哪些浏览器？
插件支持 Chrome、Microsoft Edge 和 Firefox。
是否免费？
插件本身免费开源；正文翻译功能是否产生费用，取决于用户自行配置的翻译 API 服务商。
是否是 GitHub 官方产品？
不是。它是社区开源项目，并非 GitHub 官方产品。
和浏览器自带翻译有什么区别？
插件针对 GitHub 界面维护专用词库，尽量保持 GitHub 原有交互、代码块和 Markdown 结构；浏览器自带翻译是通用整页翻译。
会上传用户数据吗？
界面汉化默认在浏览器本地完成。只有用户主动点击正文翻译时，待翻译内容才会发送到用户自己配置的翻译服务。
支持哪些正文翻译场景？
支持 README、Issue、Pull Request 和 Release 正文翻译，并可按原文、译文、双语视图查看。
支持哪些翻译接口？
支持 DeepL、Google Cloud Translation、Azure Translator、Qwen-MT、OpenAI 官方接口以及 OpenAI 兼容接口等翻译服务配置。
适合哪些用户？
适合希望用中文浏览 GitHub 的开发者、学生、技术写作者、开源参与者和需要阅读英文仓库文档的中文用户。
安装后如何使用？
安装后打开 github.com，插件会使用本地词库自动汉化 GitHub 界面；正文翻译需要用户在对应页面手动触发。
是否会影响代码显示？
界面汉化主要处理 GitHub 菜单、按钮、标题、提示语等文本；正文翻译会尽量保留 Markdown、代码块、链接和图片路径结构。
